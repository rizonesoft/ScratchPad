# Review records

Per-section review findings live here, one file per reviewed section, committed with the review:

```
docs/reviews/<domain>/D<NN>-T<NN>-s<N>.md
```

Each file records the candidate (hashes), the per-lens verdicts with findings, and the evidence that earned the stamp. A `Review:` line in a stamp points here; a verdict with no file here is an opinion, not a review.
