## Lessons

- PowerShell automatic variables (`$Pid`) are read-only: never use them as parameter names (caught by the suite, renamed `$ProcId`).
- `Get-Content` lines carry PSPath/PSDrive/PSProvider/ReadCount into `ConvertTo-Json`, which expands the provider graph to the depth limit (a 41-char line reads 25KB at depth 2 and spins to GBs at depth 8 without returning); the `[string[]]` cast strips every note property. Proved by bisection (marked copy stalled exactly at the JSON call, per-property probe at the first file-derived value), fixed in `Read-RawLines`, pinned by 4 fixtures.
- `[pscustomobject]` never gains properties by assignment (`$o.new = x` throws); always `Add-Member`. The backfill's note line threw only after rows started parsing, which is why probes missed it.
- Single-quote strings do not unescape: a `-like 'task \\X*'` pattern wants two literal backslashes and never matches one.
- New tracked files beside a checksummed set must join the checksums in the same change: `result.json` faulted retention verify as unlisted until SHA256SUMS plus the manifests grew the line, and `ack-*.md` faulted the evidence dir as manifest-without-bytes until it moved to `docs/nightly-acks/`.
- A check that reads a pointer must capture it before the run repoints it: latest.txt moves at core publication, so the ID check verifies the inherited pointer (chain of custody), not a late re-read.
