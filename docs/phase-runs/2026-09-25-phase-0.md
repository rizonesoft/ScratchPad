## Lessons

- Measure a platform assumption before encoding it: the §34 thread rule looked right on paper and would have skipped the only helper the first birth creates. The sweep log made that visible on the first run.
- The residual chain grows one section per stamped section (§28 to §41 so far). Each plan review files more hardening than it closes, so the D00 T02 tail does not converge on its own; worth an operator decision on a stopping rule.

- PowerShell unrolls a one-element array returned from `$()`; persist arrays with the comma operator, or a round trip turns them into strings.

- The Write tool decodes `§` in file content into a literal section sign. In BOM-less PowerShell files, sweep code lines for the literal after writing, or build the character with [char]0xA7.

- Recovery tooling needs its own adversarial pass: each round on the §30 rebuild found the next way a restore could thin history (replay order, empty snapshots, aged-out incidents, invalid and duplicate rows). Validate the restore source whole before trusting any of it.

- A fingerprint regenerated outside the quiet window undercounts fenced Theory cases; regenerate with SCRATCHPAD_INTERACTIVE_FORCE=1 until D00 T02 §29 makes discovery time-independent.
- When a sign-off finding is the third patch of one unit, file the execution-based replacement instead of a fourth syntactic patch.

- 2026-09-25: grep for writers before claiming a script writes no tracked file. The §22 and §23 docs said the unattended nightly writes none, but `Add-CollectedLine` (tools/NightDebt.ps1) appends §10's green-collection `Night-collected:` lines to TODO files; corrected forward in the docs and in §22's item 7 note while building §27.

- 2026-09-25: under Windows PowerShell 5.1 with `$ErrorActionPreference = 'Stop'`, a native command writing to stderr throws even with `2>$null`; scope the preference to `Continue` around git probes that may fail and read `$LASTEXITCODE`. Also keep `§` out of code strings in BOM-less `.ps1` files (5.1 reads them as ANSI): use `§` in regex and `[char]0xA7` in strings.

- 2026-09-25: the Bash tool mangles backslash escapes inside quoted heredocs (`\b` arrived as a backspace byte in a regex); write multi-line patches to a scratch `.py` file with the Write tool and run it, and grep for control bytes (`grep -c $''`) after any shell-driven edit of a regex.

- 2026-09-25: regenerate `tests/UI/TestPopulation.fingerprint` only after a fresh build of the UI tests; the regen reads the built binaries, and a stale build records the wrong case counts (a Theory's rows count as cases). Filed as `D00 T02 §29` item 4.
